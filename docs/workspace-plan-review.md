# 自由回答与方案评审

Workspace 的 Orchestrator 终端下方提供「自由回答」。可以直接填写多行回答，或在「对应问题／要修改的旧答案」中标明 Q28 等问题编号。Enter 换行，Ctrl/⌘ + Enter 发送。这个输入框适用于对话式访谈；不会替代 CLI 自己的权限批准、登录或原生选项菜单。

点击「方案文档」可以在 Hive 内查看项目根目录的 Markdown、`docs/**/*.md` 和 `.hive/tasks.md`。例如选择 `docs/prototype-plan.md`，在「预览」「编辑草稿」「修改差异」间切换。支持标题、列表、表格、代码块和面板内的文档链接；Mermaid 目前显示为代码，不会加载远程图片或执行文档中的 HTML。

## 修改与确认

1. 编辑正文或填写修改说明。
2. 「保存草稿」只写入 Hive 数据库，不覆盖项目文件，不发送给模型。未保存的编辑保留在当前浏览器；浏览器存储不可用时会提示。
3. 「发送修改供复核」先保存当前草稿，再把基准原文、修改正文、差异和说明提交给当前 Orchestrator。它要求模型只修订方案、解释影响并等待确认，而不是开始实现。
4. 查看终端中的模型回复，再点击「重新读取原文」。如果模型更新了原文件，先检查最新原文，复制保留还需要的个人修改，再选择「用最新原文替换草稿」。
5. 当前草稿没有未保存的修改、与最新项目原文一致，且不存在版本冲突时，可以「确认原文此版本」。未经编辑的原文无需先保存草稿。这只记录该版本的确认，不向模型发送命令，也不会启动实现；如需实现，请另行明确下达任务。

项目文件或另一个窗口的草稿发生变化时，Hive 会阻止覆盖或发送陈旧内容。旧版本的确认不会自动应用到新版本。

## 提交状态

- 尚未发送：启动 Orchestrator，或等上一条提交完成后重试。
- 提交中：正在等待终端接收，不要重复在终端粘贴。
- 尚未核实提交结果：请求已尝试发送，但 Hive 尚未取得回执。先点击「检查提交状态」查询回执，并检查终端；不要直接重复发送。查询状态不会重新发送正文。
- 已提交到终端：不等于模型已经阅读、采纳或通过评审，请检查模型回复。
- 发送结果不确定：可能只发送了部分内容。先检查终端；Hive 不会自动重放。运行时重启时尚未完成的提交也会进入此状态。

重复提交同一个请求不会重复注入终端。不同 Workspace 的草稿和回执相互隔离。草稿、确认记录和回执存储在当前 Hive 运行时的 SQLite 中；更换数据目录不会自动迁移这些记录。

单篇 Markdown 与草稿限 64 KB UTF-8；不读取符号链接、工作区外文件或其他隐藏目录。Web 和 Electron 共用相同后端能力。远程手机控制页仍使用已有终端输入，不提供此新评审面板。
