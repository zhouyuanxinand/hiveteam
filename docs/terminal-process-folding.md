# 终端执行过程折叠

Codex 成员和编排者的终端默认开启“折叠过程”。执行过程中，公开的进度说明、工具调用和返回内容放在展开的“正在执行…”区域；原生会话给出最终答复后，该轮过程自动收起，用户问题和完整答复保留在外面。

- 点击“执行过程”，或聚焦标题后按 Enter，可以重新展开。手动展开的状态不会被记录刷新、窗口缩放或下一轮答复重置。
- 关闭右上角“折叠过程”可查看原始终端。它与折叠视图使用同一个 PTY 和输入框。
- 审批界面、原生全屏界面和向上滚动的终端历史仍由 CLI 显示。HiveTeam 不修改原生输出，也不代替用户回答审批。
- 中断的过程会保留并标注；达到历史读取上限时显示截断提示。

## 会话记录

整轮折叠读取本轮运行已确认关联的 Codex 原生会话记录，约每两秒刷新。它包含公开的进度说明和工具输入输出，不读取模型私有推理。多条最终答复按顺序保留。

“等待当前会话记录…”表示该运行尚未建立可靠的会话关联。记录读取失败、未关联或 CLI 不支持时，终端继续可用；已有的单次工具调用折叠也可继续显示。HiveTeam 不会根据终端里的一句“完成”或上一次成员的会话 ID 猜测本轮已经结束。

升级后，已经启动的后端和 CLI 进程不会自动替换。完成或保存当前任务，再重启工作树的 Hive runtime 和成员，才能使用新建运行的完整会话关联；保留原数据目录即可。

## 手动验收

1. 启动 Codex 成员，让其执行一个包含文件读取和分析的任务，确认执行时过程可见。
2. 等待最终答复，确认过程自动收起，所有结论段落可见。
3. 展开“执行过程”，确认能看到公开进度、工具参数和输出；等待数秒并缩放窗口，确认仍保持展开。
4. 输入第二个问题，确认第一轮结论保留，第二轮过程独立展开、完成后独立收起。
5. 关闭再开启“折叠过程”，确认原生输入、中文输入和终端历史仍然可用。
