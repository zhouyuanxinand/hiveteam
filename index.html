三种分工

蜂巢里没有英雄。

没有一个 Agent 干完整个项目，每个只负责最擅长的那段。

$ team send claude
"写：给设置页加暗色模式"

$ team send codex
"审：挑这版 diff 的毛病"

← codex report:
2 处边界问题，得再改一轮

写 + 审

两家模型互相挑刺，比一家自查狠得多。改完再审一轮，你只看最终 diff。

$ team send gemini
"写测试，全量跑一遍"

← gemini report: 3 条红

$ team send claude
"修掉这 3 条红"

测 + 修

红绿循环在巢里自己转。什么时候算绿、什么时候收工——你说了算。

$ team send researcher
"核查引用的 5 个来源"

$ team send translator
"把结论翻成英文"

← researcher report:
两条站不住，已附出处

这个分支

源码在手的巢，才是自己的巢。

HiveTeam 是一个源码可控的自托管分支：你运行的每一行代码，都能在你 checkout 的那个 commit 里找到。

one repo

一个仓库装下全部

运行时、Web 工作台、远程访问网关 gateway/，全在这一个仓库里。没有闭源拼装件，没有"安装包里多出来的部分"。

no update channel

不查更新通道

不访问 npm，不问上游 release。升级就是 git pull，跑的永远是你亲自选中的那个版本——变没变，diff 说了算。

127.0.0.1 only

默认只听本机

服务绑定 127.0.0.1，本机之外没有入口。远程访问默认关闭：不打开这个开关，通路就不存在。

license in the open

许可证摊开写

BSL 1.1：个人使用、内部部署、fork 都可以；名称与标识的使用归 TRADEMARK.md 管。敏感仓库上手前，先读 SECURITY.md。

阵容

已经在巢里的，和能加入的。

九个预设开箱即用——而那只是开始。你电脑上能跑的任何 Agent，HiveTeam 里都能跑：用你已经登录好的 CLI 就行，HiveTeam 自己不要账号、不要 key。

Claude Code Codex CLI Gemini CLI OpenCode AAntigravity CCursor CLI GGrok Build HHermes QQwen Code $自定义命令

CLI 需要你自己安装并完成登录——HiveTeam 不代装、不代收号，只负责把它们编成一支队伍。

Remote Access · 可选 · 默认关闭

人出了门，蜂巢还醒着。

手机浏览器登录，跟桌面配对一次，就能从外面打开家里正跑着的蜂巢——不只是看一眼：终端在手机上能直接打字，活儿照样派。

端到端加密

手机到本机全程密文，网关只做中转——数据与执行永远在本机。

不开任何端口

本机主动出站连接。不需要公网 IP，也不暴露端口。

信任根在桌面

新设备配对必须人在电脑前确认；任何设备随时可吊销。

网关源码公开

远程网关的实现就躺在仓库的 gateway/ 目录里——加密链路长什么样，你自己审。

安装

四条命令，造一座蜂巢。

需要 Node.js ≥ 22 和 pnpm。macOS / Linux 是一等公民，Windows 尽力而为。

terminal 
$ git clone https://github.com/zhouyuanxinand/hiveteam.git
$ cd hiveteam
$ pnpm install
$ pnpm dev
# 打开它打印的本机地址，通常是 http://127.0.0.1:3000

更新也简单：git pull，然后 pnpm install --frozen-lockfile && pnpm build，重启进程即可。
